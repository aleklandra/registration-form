# Форма регистрации 🐈

Учебная форма регистрации для семинара по системному анализу. Телефон, пароль, подтверждение — и кот, который закрывает глаза, когда вы вводите пароль.

Написали **Илья Зайцев, Иван Гриценко и Даниил Петров**. Ветка команды — `Group_4`.

## Запуск

Откройте `index.html` в браузере. Устанавливать зависимости и собирать проект не нужно.

Либо поднимите локальный сервер из папки проекта:

```sh
python3 -m http.server 8000
```

Затем откройте <http://localhost:8000>.

## Что можно потыкать

- Заполнить форму: кнопка станет доступна, когда все три поля пройдут проверку.
- Поменять пароль после заполнения подтверждения: совпадение проверится заново.
- Нажать на кота: полетят коты, лапы и звёзды.
- Отправить корректную форму: будет салют и сообщение об успехе.
- Изменить любое поле после отправки: старое сообщение исчезнет.
- Отключить анимацию кнопкой в шапке. Системная настройка уменьшенного движения тоже учитывается.

Это демонстрация интерфейса: аккаунты не создаются, телефон и пароль никуда не отправляются и не сохраняются.

## Проверка полей

| Поле | Правило |
| --- | --- |
| Телефон | 11 цифр, первая — `7` или `8`. Пробелы, скобки и дефисы допускаются. |
| Пароль | Минимум 8 символов и средняя или высокая оценка по встроенной шкале. |
| Подтверждение | Непустое значение, полностью совпадающее с паролем. |

Шкала пароля начисляет по баллу за длину от 8 символов, цифру, символ вне латинских букв и цифр, сочетание прописных и строчных латинских букв. Для средней оценки нужны два балла. Это простая учебная эвристика, не проверка устойчивости к взлому.

## Файлы

```text
index.html   разметка, форма и SVG-кот
style.css    оформление, внешний фон, адаптивность и анимации
script.js    валидация, состояния формы и частицы
```

Фон загружается [по прямой ссылке пользователя](https://i.pinimg.com/originals/68/4e/5e/684e5e33931e1033e764c36e35779879.jpg?nii=t) с Pinterest. Без доступа к изображению останется тёмная подложка. Кот нарисован встроенным SVG; шрифты системные, библиотек и трекеров нет.

## Быстрая проверка перед PR

```sh
node --check script.js
git diff --check
```

В браузере проверьте пустую форму, неверный телефон, короткий пароль, несовпадение паролей и успешную отправку. После успеха измените каждое поле по очереди: сообщение должно исчезать. Проверьте узкий экран, переход между элементами клавишей Tab и отключение анимации.

На семинаре команды исправляют ошибки в своих ветках и отправляют PR. Наши изменения идут из форка в `aleklandra/registration-form:Group_4`.
