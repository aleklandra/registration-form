# Форма регистрации

Учебная форма регистрации с проверкой телефона и пароля. Проект написан на HTML, CSS и JavaScript, установка и сборка не нужны.

Автор: Брюхов Иван.

## Запуск

Откройте `index.html` в браузере. Для работы формы должен быть включён JavaScript.

## Возможности

- **Телефон.** Номер автоматически приводится к формату `+7(XXX)XXX-XX-XX`. После кода `+7` можно ввести не более десяти цифр. На мобильных устройствах браузер может показать телефонную клавиатуру.
- **Пароль.** Должен содержать не менее 8 символов, хотя бы одну цифру от `0` до `9` и хотя бы один спецсимвол. Буквы, числа и пробелы не считаются спецсимволами.
- **Требования к паролю.** После начала ввода под полем появляется список требований. Выполненные пункты отмечены зелёной галочкой, невыполненные — красным крестиком. Если очистить поле, список скрывается.
- **Подтверждение пароля.** Повторный пароль должен полностью совпадать с введённым, включая регистр букв.
- **Сообщения об ошибках.** Форма сообщает о неверном номере и несовпадении паролей. При выходе из пустого поля телефона или подтверждения появляется сообщение «Обязательное поле».
- **Кнопка регистрации.** Заблокирована, пока все поля не заполнены правильно. При отключённом JavaScript кнопка остаётся заблокированной.
- **После отправки.** При корректных данных форма скрывается и появляется поздравление. Окно сохраняет прежнюю высоту.
- **Доступность.** Поля связаны с сообщениями об ошибках. Ошибочные поля обозначаются для программ чтения экрана, а сообщения об ошибках подготовлены к озвучиванию. Состояние требований к паролю также передаётся текстом.

## Важно

Форма работает только в браузере: данные не сохраняются и аккаунт не создаётся. Поздравление означает, что введённые данные прошли проверку.

## Файлы проекта

- `index.html` — разметка формы.
- `style.css` — оформление.
- `script.js` — проверка данных и управление состоянием формы.
