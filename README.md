# Форма регистрации

Учебный проект на HTML, CSS и JavaScript. Форма проверяет номер телефона, оценивает сложность пароля и проверяет его подтверждение во время ввода.

## Что делает форма

### Номер телефона

- Приводит номер к формату `+7XXXXXXXXXX`: 11 цифр, включая код страны `7`.
- При вводе первой `7`, `8` или знака `+` автоматически подставляет `+7`.
- Перед другой первой цифрой добавляет `+7`, сохраняя введённую цифру.
- Удаляет буквы, пробелы, скобки и другие посторонние символы, в том числе при вставке из буфера обмена.
- Ограничивает номер десятью цифрами после `+7`; лишние цифры отбрасываются.
- Показывает ошибку, если непустой номер заполнен не полностью.

Примеры преобразования при вставке:

| Введённое значение | Результат |
| --- | --- |
| `89991234567` | `+79991234567` |
| `79991234567` | `+79991234567` |
| `9991234567` | `+79991234567` |
| `+7 (999) 123-45-67` | `+79991234567` |

### Пароль и подтверждение

- Показывает индикатор сложности пароля, который меняет цвет и заполнение.
- Требует минимум 8 символов и хотя бы один дополнительный признак: цифру, символ вне латинских букв и цифр либо сочетание строчных и заглавных латинских букв.
- Проверяет точное совпадение пароля и подтверждения.
- Повторно проверяет подтверждение при изменении основного пароля.

### Отправка формы

Кнопка регистрации доступна только при корректном номере телефона, подходящем пароле и заполненном подтверждении, совпадающем с паролем. После отправки появляется сообщение об успешной регистрации без перезагрузки страницы.

Это демонстрация проверки данных в браузере: форма не создаёт учётную запись, не отправляет данные на сервер и не сохраняет их. Проверяется только формат телефона; принадлежность и существование номера не проверяются.

## Как запустить

Откройте `index.html` в браузере. Установка зависимостей, сборка и сервер не требуются. Также можно открыть страницу через расширение Live Server в VS Code.

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `index.html` | Разметка формы и полей ввода |
| `style.css` | Оформление формы, ошибок и индикатора сложности |
| `script.js` | Форматирование телефона, проверка данных и обработка отправки |

## Как использовать на занятии

1. Залейте этот проект в `main` — это ЭТАЛОННАЯ рабочая версия без багов.
2. Создайте 4 ветки от `main`, в каждой внесите один точечный баг (см. ниже) — это будут стартовые ветки для команд.
3. На занятии каждая команда получает свою ветку, копию репозитория (fork) или доступ на редактирование, и работает с ИИ, чтобы найти и исправить баг.
4. Каждая команда открывает Pull Request в `main`.
5. Вы по очереди мёржите PR, обновляете открытый `index.html` (или деплой) и показываете исправление на экране.
