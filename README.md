## Обновления формы регистрации

В рамках доработки проекта были внесены следующие изменения:

### 📱 Улучшен ввод номера телефона
- Доработано поле ввода номера телефона для корректного отображения вводимых данных.
- Улучшено форматирование номера телефона для более удобного заполнения формы.
- Повышено удобство взаимодействия с полем ввода.

### 🌸 Обновлён пользовательский интерфейс
- Разработан более современный и привлекательный дизайн формы регистрации.
- Добавлены изображения аниме-девушек в качестве визуального оформления.
- Улучшено общее восприятие интерфейса и удобство использования формы.

### Результат
Форма регистрации стала более удобной и визуально привлекательной. Изменения направлены на улучшение пользовательского опыта (UX) и внешнего вида интерфейса (UI).
